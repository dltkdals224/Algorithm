# Memoization

Top-Down DP: 큰 문제 → 작은 문제로 재귀를 내려가며, 이미 계산한 값은 메모에 저장해 중복 계산을 회피.

핵심 아이디어: 상태(state) 정의 -> 점화식(전이) -> 기저 조건 -> 메모 저장 및 재사용

## 문제 풀이

### 문제

[퇴사](https://www.acmicpc.net/problem/14501)

### 풀이

```python
input = sys.stdin.readline

N = int(input())
dp = [0] * (N + 1)
interview = []

for _ in range(N):
   interview.append(list(map(int, input().split())))

for idx in range(N):
   current_day = N - idx
   T, P = interview[N - (idx + 1)]

   if current_day + T - 1 <= N:
       next_day_idx = current_day + T - 1
       take_interview = P + dp[next_day_idx]
       skip_interview = dp[current_day]
       dp[current_day - 1] = max(take_interview, skip_interview)
   else:
       dp[current_day - 1] = dp[current_day]

print(dp[0])
```

```python
# 강의 기반의 풀이
import sys
sys.setrecursionlimit(1_000_000)
input = sys.stdin.readline

def recursion(idx):
    global answer

    # 기저 조건: idx가 N 이상이면 더 못 벌음
    if idx >= N:
        return 0

    if dp[idx] != -1:
        return dp[idx]

    # 상담 선택 / 미선택
    t, p = interview[idx][0], interview[idx][1]

    # 상담 가능할 때만 선택 분기
    take = recursion(idx + t) + p if idx + t <= N else 0
    skip = recursion(idx + 1)

    dp[idx] = max(take, skip)
    return dp[idx]

N = int(input().strip())

interview = []
for _ in range(N):
    interview.append(list(map(int, input().split())))  # [t, p]

dp = []
for _ in range(N + 1):
    dp.append(-1)
dp[N] = 0

answer = 0
answer = recursion(0)

print(answer)
```
