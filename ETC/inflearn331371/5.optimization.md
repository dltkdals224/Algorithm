## 문제 풀이

### 문제

⚠️ [도영이가 만든 맛있는 음식](https://www.acmicpc.net/problem/2961)

### 풀이

```python
# 나의 풀이
ans = float('inf')

def recur(idx, S, B, mix_count):
    global ans  # 전역 변수 ans를 사용하겠다는 뜻
    if idx == N:
        if mix_count != 0:
            ans = min(ans, abs(S - B))
        return  # mix_count 값과 상관없이 종료는 필요 <- 놓치기 쉬운 부분

    recur(idx + 1, S * ingre[idx][0], B + ingre[idx][1], mix_count + 1)
    recur(idx + 1, S, B, mix_count)

N = int(input())
ingre = [list(map(int, input().split())) for _ in range(N)]

recur(0, 1, 0, 0)

print(ans)
```

### 문제

⚠️ [다이어트](https://www.acmicpc.net/problem/19942)

앞선 문제 '[도영이가 만든 맛있는 음식](https://www.acmicpc.net/problem/2961)'의 풀이와 굉장히 유사.

### 풀이

```python
def recur(idx, p, f, s, v, cost, path):

    global best_cost, best_path
    if idx == N:
        if p >= gp and f >= gf and s >= gs and v >= gv:
            if cost < best_cost or (cost == best_cost and path < best_path):
                best_cost = cost
                best_path = path[:]  # 사전순 비교 위한 경로 저장
        return
    
    # 식재료 포함 O
    path.append(idx + 1)  # 1-based 인덱스
    ip, if_, is_, iv, ic = ingredient[idx]
    recur(idx + 1, p + ip, f + if_, s + is_, v + iv, cost + ic, path)
    path.pop()
    # 식재료 포함 X
    recur(idx+1, p, f, s, v, cost, path)

N = int(input())
gp, gf, gs, gv = map(int, input().split())

best_cost = float('inf')
best_path = []

ingredient = [list(map(int, input().split(' '))) for _ in range(N)]
recur(0,0,0,0,0,0,[])

if best_cost == float('inf'):
    print(-1)
else:
    print(best_cost)
    print(*best_path)
```

### 설명

1) cost == best_cost and path < best_path

동일 비용 후보가 여러개면, 인덱스 열 path가 사전순으로 더 앞서는지 비교.

2) best_path = path[:]

path[:]는 얕은 복사(새 리스트 생성). 현재 path의 내용을 스냅샷으로 저장.  
best_path = path처럼 참조만 넘기면, 이후 path.pop()때 best_path도 같이 바뀌어서 오답.

3) print(*best_path)

*는 언패킹(unpacking) 연산자.  
리스트의 원소들을 개별 인자로 풀어서 print에 전달.

' '.join(map(str, _))은 값의 할당이 필요할 때 사용하지만,  
print로 출력만 하는 경우에는 언패킹이 보다 적절.3333

```python
def recur(day, money_sum):
    global ans
    if day >= N:  # 모든 날을 다 확인했을 때  # !
        ans = max(ans, money_sum)
        return

    # 상담 수행
    if day + LIST[day][0] <= N:
        recur(day + LIST[day][0], money_sum + LIST[day][1])

    # 상담 스킵
    recur(day + 1, money_sum)

ans = float('-inf')
N = int(input())
LIST = [list(map(int, input().split())) for _ in range(N)]

recur(0, 0)
print(ans)
```

```python
# DP (점화식)
import sys
input = sys.stdin.readline

N, K = map(int, input().split())
items = [tuple(map(int, input().split())) for _ in range(N)]  # (W, V)

# dp[w] = 최대 무게 w에서의 최대 가치
dp = [0] * (K + 1)

for W, V in items:
    # 0/1이라 같은 물건을 여러 번 쓰지 않도록 w를 내림차순으로
    for w in range(K, W - 1, -1):
        # 안 담기 vs 담기
        dp[w] = max(dp[w], dp[w - W] + V)

print(dp[K])
```
