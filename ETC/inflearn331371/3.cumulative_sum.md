# Cumulative Sum

컴퓨터는 자체적으로 이전 과정에서의 연산을 재사용하지 못한다.  
컴퓨터에게 **기억하는 방법**을 알려주는 문제들.

기억 누적합 > 탑다운 DP, 바텀업 DP, 메모이제이션

=> 유니온파인드, 프림, 크루스칼  
이 수준의 도달에서 모든 코딩테스트 문제 풀이 가능

관찰하고 생각하는 힘에 대해서만 강의.  
풀이(python skill)는 개인적으로 따로 공부.

## 문제 풀이

### 문제

[수열 (#2559)](https://www.acmicpc.net/problem/2559)

### 풀이

```python
# 나의 풀이
[COUNT, CONTINUOUS] = list(map(int, input().split()))
INPUT = list(map(int, input().split()))

cumulative_sum = sum(INPUT[0:CONTINUOUS])
max_sum = sum(INPUT[0:CONTINUOUS])

for _, idx in enumerate(range(COUNT - (CONTINUOUS))):
    cumulative_sum -= INPUT[idx]
    cumulative_sum += INPUT[CONTINUOUS + idx]
    if(cumulative_sum > max_sum):
        max_sum = cumulative_sum

print(max_sum)
```

```python
# 강의 풀이
COUNT, CRITERIA = map(int, input().split())
arr = list(map(int, input().split()))

answer = []
prefix = [0 for _ in range(COUNT + 1)]

for idx in range(COUNT):
    prefix[idx + 1] = prefix[idx] + arr[idx]

for k in range(CRITERIA, COUNT + 1):
    answer.append(prefix[k] - prefix[k - CRITERIA])

print(max(answer))
```

### 설명

누적합(prefix) 배열을 최초로 생성.  
(* prefix 배열은 기준 배열보다 length를 하나 크게 생성)

prefix 배열 기준 특정 index 사이의 연산만으로 답 생성 가능.

### 문제

[연속합 (#1912)](https://www.acmicpc.net/problem/1912)

### 풀이

```python
# 누적합 사용하는 풀이
COUNT = int(input())
INPUT = list(map(int, input().split()))

prefix = [0] * (COUNT + 1)
for i in range(COUNT):
    prefix[i + 1] = prefix[i] + INPUT[i]

max_sum = float('-inf')
min_prefix = prefix[0]

for i in range(1, COUNT + 1):
    max_sum = max(max_sum, prefix[i] - min_prefix)
    min_prefix = min(min_prefix, prefix[i])

print(max_sum)
```

```python
# DP를 사용하는 풀이
COUNT = int(input())
INPUT = list(map(int, input().split()))

dp = [0] * COUNT
dp[0] = INPUT[0]

for i in range(1, COUNT):
    dp[i] = max(dp[i-1] + INPUT[i], INPUT[i])

print(max(dp))
```

### 설명

누적합을 사용하는 풀이에서 다음을 주의.

'prefix 배열에서 전역 최댓값의 인덱스(max_idx)와 그 이전까지의 전역 최솟값의 인덱스(min_idx)를 찾기'가 답이 될 수 없는 이유는 다음과 같다.

최댓값이 여러 개인 경우 .index()는 첫 번째 발견된 인덱스만 반환하기 때문.

### 풀이

```python
arr = []

COUNT = int(input())
for _ in range(COUNT):
    [x, y] = map(int, input().split())
    arr.append([x,y])
arr.sort(key=lambda x:x[0]) # !

max_height_idx = max(range(len(arr)), key=lambda t: arr[t][1]) # !

ans = 0
left_coor, right_coor = arr[0][0], arr[-1][0]

# left
left_idx = 0
max_height = 0
for i in range(max_height_idx + 1):
    if arr[i][1] > max_height:
        if i > 0:
            ans += (arr[i][0] - left_coor) * max_height
        left_coor = arr[i][0]
        max_height = arr[i][1]

print(ans)

# right
right_idx = len(arr) - 1
max_height = 0
for i in range(len(arr) - 1, max_height_idx - 1, -1):
    if arr[i][1] > max_height:
        if i < len(arr) - 1:
            ans += (right_coor - arr[i][0]) * max_height
        right_coor = arr[i][0]
        max_height = arr[i][1]

print(ans)

# 최대 높이 기둥 추가
ans += (right_coor - left_coor + 1) * arr[max_height_idx][1]

print(ans)
```

```python
ans = 0
[H, W] = list(map(int, input().split()))  # H: 세로, W: 가로
heights = list(map(int, input().split()))  # 각 열의 높이

# 빗물의 양 계산
for i in range(1, W-1): 
    left_max = max(heights[:i])  # 현재 위치의 왼쪽에서 가장 높은 블록
    right_max = max(heights[i+1:])  # 현재 위치의 오른쪽에서 가장 높은 블록
    
    # 현재 위치(=x축)에 고일 수 있는 빗물의 양
    water_level = min(left_max, right_max)
    if water_level > heights[i]:
        ans += water_level - heights[i]

print(ans)
```

### 문제

⚠️ [구간 합 구하기 5 (#11660)](https://www.acmicpc.net/problem/11660)

### 풀이

```python
import sys
input = sys.stdin.readline

N, count = map(int, input().split())

# 2차원 누적합 배열 생성 (1-indexed로 처리하기 위해 크기를 N+1로 설정)  # !
prefix_sum = [[0] * (N + 1) for _ in range(N + 1)]

# 원본 배열 입력받음과 동시에 누적합 계산
for i in range(1, N + 1):
    row = list(map(int, input().split()))
    for j in range(1, N + 1):
        # 2차원 누적합 공식: prefix_sum[i][j] = 원본값 + 위쪽 누적합 + 왼쪽 누적합 - 대각선 누적합  # !
        prefix_sum[i][j] = row[j-1] + prefix_sum[i-1][j] + prefix_sum[i][j-1] - prefix_sum[i-1][j-1]

# 쿼리 처리
for _ in range(count):
    x1, y1, x2, y2 = map(int, input().split())
    
    # 구간 합 공식: 전체 - 위쪽 제외 - 왼쪽 제외 + 대각선 중복 제외된 부분 복구
    ans = prefix_sum[x2][y2] - prefix_sum[x1-1][y2] - prefix_sum[x2][y1-1] + prefix_sum[x1-1][y1-1]
    
    print(ans)
```

### 설명

최초의 풀이에서 쿼리 처리 과정 내 **시간 초과** 발생.  
구간합 공식을 row에 한정하지 않고, column까지 확장할 필요성 존재.  

그렇게 하기 위해 2차원 누적합 그래프의 구간합 공식을 알고있어야 함.  
1. 'prefix_sum 생성' 누적합 계산: 원본 + 상단 + 좌측 - 대각(좌측 상단)

2. '쿼리 처리' 누적합 계산: 전체 - 범위 외 상단 - 범위 외 좌측 + 범위 외 대각(좌측 상단)  
    가령 (2,2)부터 (4,4)까지 누적합이라면, 누적합 그래프에서 (4,4) - (1,4) - (4,1) + (1,1)

<br/>

누적합 배열 연산과정 내 편의성을 위해, 1-indexed 연산 처리용 배열 N+1 설정이 굉장히 유용하다.

### 문제

⚠️ [개똥벌레 (#3020)](https://www.acmicpc.net/problem/3020)

통칭 **이모스 법(이모스의 장애물 경주)**.  
2012년 일본의 어느 대학원생이 고안해낸 방법으로, **누적 합 알고리즘을 다차원 및 다차수로 확장**한 것이다.

### 풀이

```python
import sys
input = sys.stdin.readline

N, H = map(int, input().split())

# 차분 배열 사용 (구간 업데이트를 O(1)에 처리)  # !
diff = [0] * (H + 1)

for idx in range(1, N + 1):
    obstacle_type = idx % 2  # 1: 석순 / 0: 종유석
    obstacle_height = int(input())
    
    if obstacle_type == 1:
        # 구간 [0, obstacle_height-1]에 +1
        diff[0] += 1
        diff[obstacle_height] -= 1
    else:
        # 구간 [H-obstacle_height, H-1]에 +1
        diff[H - obstacle_height] += 1
        diff[H] -= 1

# 차분 배열을 실제 배열로 변환 (누적합 적용)
arr = [0] * H
arr[0] = diff[0]
for i in range(1, H):
    arr[i] = arr[i-1] + diff[i]

# 최솟값과 그 개수 찾기
ans = min(arr)
print(ans, arr.count(ans))
```

### 설명

차분 배열을 사용하지 않고 for문에서 리스트에 index 접근하는 구조는 **시간 초과** 발생.

차분 배열의 핵심은 **구간 업데이트를 나중에 일괄 처리**하는 아이디어.  
구간 [L, R]에 +V를 하고 싶다면, L 지점에 "여기서부터 +V 시작", R+1 지점에 "여기서부터 +V 끝" 표시  
(해당 문제에서는 누적합 관점에서 L 지점에 1을, R+1 지점에 -1을 넣어 표시함)

### 문제

⚠️ [직각다각형 (#17611)](https://www.acmicpc.net/problem/17611)

### 풀이

```python
import sys
input = sys.stdin.readline

count = int(input())
points = []

# 좌표 이터러블화
for _ in range(count):
    x, y = map(int, input().split())
    points.append((x, y))

points.append(points[0])

# 선분 추출
vertical_segs = []    
horizontal_segs = []  

for i in range(count):
    x1, y1 = points[i]
    x2, y2 = points[i + 1]
    
    if x1 == x2 and y1 != y2:
        vertical_segs.append((min(y1, y2), max(y1, y2)))
    elif y1 == y2 and x1 != x2:
        horizontal_segs.append((min(x1, x2), max(x1, x2)))

# 좌표압축
y_coords = sorted(set(y for y1, y2 in vertical_segs for y in [y1, y2]))
x_coords = sorted(set(x for x1, x2 in horizontal_segs for x in [x1, x2]))

# 최대 교차 횟수 계산
def get_max_intersect(segments, coords):
    if not coords: return 0
    diff = [0] * len(coords)
    
    for start, end in segments:
        diff[coords.index(start)] += 1
        diff[coords.index(end)] -= 1
    
    max_val = current = 0
    for i in range(len(coords) - 1):
        current += diff[i]
        max_val = max(max_val, current)
    
    return max_val

max_h = get_max_intersect(vertical_segs, y_coords)
max_v = get_max_intersect(horizontal_segs, x_coords)

print(max(max_h, max_v))
```
