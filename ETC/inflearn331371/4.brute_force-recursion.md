# Brute Force

가능한 모든 경우의 수를 전부 탐색하여 답을 찾는 방법.  
특별한 알고리즘 없이 **단순 반복** 또는 **완전 탐색**으로 문제를 해결.

핵심 아이디어: 모든 경우를 시도

다만 앞선 '1.brute_force'와 달리 반복문(recursion)을 사용하는 형태로 작성한다.

<br/>

## 문제 풀이

[N과 M 시리즈 (#15649, #15650, #15651, #15652, #15654, #15655, #15656)](https://www.acmicpc.net/workbook/view/2052)

자연수 N과 M이 주어졌을 때, 아래 조건을 만족하는 길이가 M인 수열을 모두 구하는 프로그램을 작성.

### 문제

[N과 M(1)](https://www.acmicpc.net/problem/15649)

1부터 N까지 자연수 중에서 중복 없이 M개를 고른 수열.

### 풀이

```python
import sys
input = sys.stdin.readline

N, M = map(int, input().split())

used = [False] * (N + 1)  # !  # index = 0은 사용하지 않음 (1 ~ N)
path = [0] * M  # !

def dfs(depth):
    if depth == M:
        print(' '.join(map(str, path)))
        return
    for num in range(1, N + 1):
        if not used[num]:
            used[num] = True
            path[depth] = num  # pick
            dfs(depth + 1)  # explore
            used[num] = False  # backtrack

dfs(0)
```

시간복잡도는 O(P(N,M)*M)

제약: 1 <= M <= N <= 8  
최악: P(8, 8) = 8! = 40320

### 설명

> 중첩 for문에서 출발하기

N=4, M=2라면 이와 같은 코드에서 출발할 수 있다:

```python
for a in range(1, N+1):
    for b in range(1, N+1):
        if a != b:
            print(a, b)
```

M=3이면 for문이 하나 더 늘어나는 구조.  
이 "중첩 for문"을 M의 증가에 관계없이 대응할 수 있도록 일반화 한 것이 현재의 dfs.

- depth: 현재 몇 번째 for문?

- used: 앞선 for문에서 어떤 숫자를 골랐는가?

- path: 각 for문의 선택 결과(부분 수열) 저장

<br/>

> 백트래킹 템플릿

대부분의 '순열/조합 탐색'은 아래 형태로 복붙처럼 풀린다.

```python
def dfs(depth):
    # (1) 종료 조건: 다 골랐으면 출력/반환
    if depth == 목표길이:
        처리(path)
        return

    # (2) 선택지 순회
    for 후보 in 후보집합:
        if (유효한가? 이미 썼나? 범위 맞나?):
            # (3) 선택 (= pick)
            상태표시(used[후보] = True, path[depth] = 후보)

            # (4) 더 깊이 (= explore)
            dfs(depth + 1)

            # (5) 원상복구 (= backtrack)
            상태원복(used[후보] = False)
```

> 파이썬 대안(by itertools)로 "문제 구조"에 대한 이해하기

```python
from itertools import permutations
import sys
input = sys.stdin.readline

N, M = map(int, input().split())
for p in permutations(range(1, N+1), M):
    print(*p)  # iterable unpacking
```

사실 이런 종류의 문제는 **permutation의 구현**이다.  
이를 통해 “문제는 길이 M의 순열을 전부 나열하는 것”이라는 문제 구조를 뇌에 박는데에 도움을 받을 수 있음.

다만 면접/코딩테스트에서는 “내장 라이브러리 쓰면 안 된다”는 제약이 종종 있으니, 두 방식을 모두 체화.
