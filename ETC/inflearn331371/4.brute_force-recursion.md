# Brute Force

가능한 모든 경우의 수를 전부 탐색하여 답을 찾는 방법.  
특별한 알고리즘 없이 **단순 반복** 또는 **완전 탐색**으로 문제를 해결.

핵심 아이디어: 모든 경우를 시도

다만 앞선 '1.brute_force'와 달리 반복문(recursion)을 사용하는 형태로 작성한다.

## 문제 풀이

### 문제

[N과 M (#15649, #15650, #15651, #15652, #15654, #15655, #15656)](https://www.acmicpc.net/workbook/view/2052)

자연수 N과 M이 주어졌을 때, 아래 조건을 만족하는 길이가 M인 수열을 모두 구하는 프로그램을 작성.

### 풀이

> [#15649](https://www.acmicpc.net/problem/15649)

1부터 N까지 자연수 중에서 중복 없이 M개를 고른 수열.

```python
import sys
input = sys.stdin.readline

N, M = map(int, input().split())

used = [False] * (N + 1)  # !
path = [0] * M  # !

def dfs(depth):
    if depth == M:
        print(' '.join(map(str, path)))
        return
    for num in range(1, N + 1):
        if not used[num]:
            used[num] = True
            path[depth] = num
            dfs(depth + 1)
            used[num] = False  # backtrack

dfs(0)
```
